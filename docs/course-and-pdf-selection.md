# Google Skills and PDF selections

Google Skills pages and their Google Storage `/cloud-training/` lesson frames load the full selection tools. The shortcut prefers the focused lesson selection over stale parent text. The popup lives in that frame, so highlights and personal notes use the real passage range. AI/translation/audio results return only to the originating frame; AI frame ownership survives worker restart. Lesson review and notes are scoped to the actual frame source.

For native PDFs, the normal selection shortcut opens **PDF actions** for URLs ending in `.pdf`. Chrome does not expose the protected viewer’s selected text to that shortcut. Right-click the selected text and choose **Word Explainer — PDF actions** to capture it, or use **Paste PDF selection → Use this selection** in the panel. Pasting stores only a local selection; it starts no external request. Extensionless PDF URLs can open the panel through the toolbar’s **PDF actions** button.

The PDF panel includes Listen, Translate, Ask to LLM, Summarize, Selection references and the Math article actions. Provider choices appear directly below Ask to LLM. Selection references request up to three sources and render complete validated reports; raw streamed JSON is hidden. Native-viewer inline highlights and notes remain unavailable. Translation/short explanation currently accept up to 1,000 characters; summary, paper explanation and references accept up to 8,000. Paper explanation requires a public source URL, and scanned PDFs require OCR/selectable text first.

Validation: `test-course-frame-ui.mjs` exercises a real cross-origin lesson fixture with actual saved CSS highlights and attached personal notes. `test-pdf-panel-ui.mjs` connects the real panel to its local service for paste validation, provider placement and streamed/final references. Backend tests cover PDF command opening, retained reference chats and exact originating-frame delivery after worker restart. The signed-in Google Skills document and actual Chrome keyboard registration still require a live user check.
